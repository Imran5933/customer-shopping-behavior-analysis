# Customer Shopping Behavior Analysis

## Project Overview

A data analysis project focused on understanding customer shopping behavior, purchasing patterns, and customer segmentation using Python, Pandas, NumPy, PostgreSQL and SQL.

## Tools & Technologies

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI

## Project Components

- Data cleaning and preparation
- Exploratory data analysis
- Customer behavior analysis
- Customer segmentation
- Purchasing pattern analysis
- SQL-based analysis
- Power BI dashboard

## Key Analysis

- Customer purchasing behavior
- Customer segmentation
- Purchase patterns
- Customer demographics
- Product and sales analysis
- Customer preferences and trends

## Files

- `Untitled-1.ipynb` — Python/Pandas/NumPy analysis
- `sql.sql` — SQL analysis
- `Customer_behavior.pbix` — Power BI dashboard
- `Report_Customer_Shopping_Beh...` — Analysis report

The Power BI dashboard provides an interactive view of customer shopping behavior and purchasing patterns.
